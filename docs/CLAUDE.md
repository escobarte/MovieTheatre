# CLAUDE.md — правила для Claude Code

Проект **Movie_Theatre**: личный каталог фильмов и сериалов на одного пользователя. Полное ТЗ — `docs/SPEC.md`, где мы сейчас — `docs/STATE.md`, история правок — `docs/CHANGELOG.md`. Этот файл дублирует то, что должно быть в контексте всегда: правила работы, карту проекта и дизайн-систему.

---

## Правила работы

**Git не трогать.** Никаких `git add`, `commit`, `push`, `branch`, `merge` и правок в `.git`. Версионирование владелец ведёт вручную сам. Задача — только менять файлы проекта.

**Changelog.** После каждого выполненного запроса дописывать сверху одну свежую запись в `docs/CHANGELOG.md`: дата, короткое (1–3 строки) описание сделанного, список затронутых файлов. Ничего не удалять из истории, только добавлять наверх.

**State.** Если запрос закрывает этап или меняет то, что описано в `docs/STATE.md`, обновить и его.

**Дизайн — строго по разделу 6 ниже.** Никакой самодеятельности в оформлении: цвета, шрифт, скругления, состояния берутся из токенов. При расхождении с макетами в `assets/` верен текст. Готовые UI-киты запрещены.

**Один запрос — один законченный кусок.** Не забегать вперёд по плану без просьбы. Закончил — обновил Changelog — остановился.

**Секреты.** Файл `.env.local` и значения ключей не читать вслух, не копировать в код и документы, в `.env.example` — только имена переменных.

**Данные.** База Turso боевая и одна. Не засевать её тестовыми записями и не выставлять личные поля (оценка, статус, заметка) от своего имени. Для проверок — только то, что владелец добавил сам.

## Стек

Next.js 15 (App Router) + TypeScript + Tailwind v4 · шрифт Onest · lucide-react · Turso (SQLite) + Drizzle ORM · TMDB + Кинопоиск (poiskkino.dev) · Auth.js v5 + Google · Vercel (проект `movie-theatre-eight`, ветка `main`). Без UI-китов, без анимационных библиотек, без Redux/Zustand: состояние фильтров живёт в URL и `useMemo`.

## 6. Дизайн-система

Тема одна, тёмная, переключателя нет. Стилистика — современный стриминговый каталог: почти чёрный фон, красный акцент на действиях, крупные постеры, скруглённые пилюли.

### 6.1. Эталонные макеты

Три статических HTML-файла лежат в папке `assets/` в корне репозитория и открываются в браузере. Это только макеты, сайт на них не построен:

```
assets/movie_theatre_home_hero_carousel.html   — Главная
assets/movie_theatre_all_films_catalogue.html  — Всё кино
assets/movie_theatre_search_empty_state.html   — Поиск и пустой результат
```

**При расхождении макета и текста ТЗ верен текст.** Макеты рисовались раньше и содержат упрощения: вместо постеров и кадров — серые подложки с иконкой, часть блоков показана в одном состоянии из нескольких. Брать из них следует пропорции, плотность, порядок блоков и ощущение — а значения цветов и размеров сверять с токенами ниже.

Один шрифт — **Onest**, начертания 400, 500 и 700. Подключать через `next/font/google` с `subsets: ['cyrillic', 'latin']`. Второго шрифта в системе нет.

| Роль | Размер | Начертание | Прочее |
|---|---|---|---|
| Логотип | 15px | 700 | `letter-spacing: .1em`, верхний регистр, подчёркивание в `--red` |
| Заголовок экрана | 22px | 700 | |
| Заголовок полки | 17px | 700 | слева иконка, цвет по 6.5 |
| Название на карточке карусели | 15px | 700 | |
| Название под постером | 12.5px | 500 | |

### 6.4. Два акцента и правило их разделения

Цветов-акцентов два, и они не пересекаются.

**Красный `--red`** — только действия и активные состояния: кнопка «Добавить», активная пилюля жанра, активный пункт навигации, «Продолжить», «Сбросить фильтры», рамка постера со статусом «Буду смотреть», курсор в поле ввода, активная точка карусели, иконка слева от заголовка полки, залитое сердце избранного.

Невыбранная пилюля жанра, переключатель типа, выпадающий фильтр и пилюля «Ещё N» / «Свернуть» получают рамку `--line-strong` вместо акцентной заливки — рамка нейтральна и в правило двух акцентов не входит. Выбранное состояние у всех них — красная заливка, кроме сортировки: у неё значение есть всегда, поэтому она остаётся в виде «не выбрано».

**Жёлтый `--gold`** — исключительно звезда рейтинга и число рядом с ней. Больше нигде, ни при каких условиях.

Правило проверки простое: если жёлтый появился не вплотную к звезде — это ошибка. Разделение работает потому, что читатель мгновенно закрепляет за жёлтым один смысл, и оценка выхватывается взглядом без подписей.

Красным нельзя набирать абзацы текста и заголовки — только элементы управления и отметки.

Цвета статусов просмотра (`--st-watching`, `--st-watched`, `--st-planned`, `--st-none`) — служебные метки, а не третий акцент: закрашивают только точку 7px перед подписью статуса и полоску прогресса сериала (6.5), сам текст статуса остаётся обычного цвета. Акцентов по-прежнему два — красный и жёлтый.

### 6.5. Компоненты

**Пилюля и фильтр (выбрано/не выбрано).** Общее правило для пилюль жанра (Главная, «Всё кино»), переключателя «Всё · Фильмы · Сериалы», выпадающих фильтров и пилюль «Ещё N» / «Свернуть»: не выбрано — фон прозрачный, рамка `1px solid var(--line-strong)`, текст `--text` 400, счётчик `--text-3`, наведение — фон `--surface-2`; выбрано — фон `--red`, рамка того же цвета, текст белый 500, счётчик и шеврон белые, наведение `--red-hover`. Пилюля жанра и «Ещё N» / «Свернуть»: `padding: 7px 15px`. Выпадающий фильтр: `padding: 7px 14px`, шеврон 13px справа, значение в подписи: `Файл: скачан`. Сортировка — исключение: у неё значение есть всегда, поэтому она всегда в виде «не выбрано», не красная.

**Основная кнопка.** Фон `--red`, белый текст, `padding: 9px 18px`, `--r-pill`, 500. Наведение — `--red-hover`. Вторичная — то же на `--surface-3`.

**Светлая кнопка** — только для кнопки «Трейлер» в карточке записи: фон `--text`, текст и иконка `--bg`, `padding: 9px 18px`, `--r-pill`, 500, иконка `Play`. Наведение — фон `#FFFFFF`. Это не новый акцент, а инверсия нейтральных цветов.

**Заголовок полки.** Иконка, название, счётчик пилюлей (`--surface-2`, `--r-pill`, `padding: 2px 8px`, 11.5px `--text-2`), дальше пустое место на `flex-grow` без фона и без линии — просто раздвигает заголовок и правый край. Цвет иконки у полок Главной: «Смотрю сейчас» — `--st-watching`, «Хочу пересмотреть» — `--violet`, «Буду смотреть, уже скачано» — `--red`, «Мои списки» — `--orange`. У полок («Смотрю сейчас», «Хочу пересмотреть», «Буду смотреть, уже скачано», «Мои списки») справа ссылка «Все →» 12.5px `--text-2` (наведение `--text`); у карусели «Последние добавленные» справа — круглые кнопки-стрелки 32px с рамкой 1px `--line-strong`, иконки в заголовке нет. У шапки сайта разделительной линии нет.

Карточка карусели — рамка 1px `var(--line)`. Панель жанров на Главной — фон `--surface`, рамка 1px `var(--line)`, `--r-lg`, `padding: 20px`, поясняющая подпись внутри панели, над пилюлями.

**Постер.** Соотношение 2:3, `--r-xs`, подложка `--surface-2`. Пока изображения нет — иконка в `--icon-dim` по центру. Под постером название, ниже строка: год слева `--text-3`; оценка справа — то же правило, что в полке и карусели (см. «Подпись у оценки» ниже).

**Подпись у оценки.** Везде, где показана оценка на постере, в полке или в карусели: если есть личная оценка — звезда и число в `--gold`, рядом подпись «моя» 11.5px `--text-3`; иначе если есть оценка КП — звезда и число в `--gold`, рядом подпись «КП»; иначе ничего не показывается. Жёлтый — только у звезды и числа рядом с ней, подпись серая.

**Точка статуса.** Везде, где статус просмотра показан текстом — выпадающий фильтр «Статус» во «Всё кино», кнопки статуса в карточке записи — перед словом идёт точка 7px цвета статуса (`--st-watching`, `--st-watched`, `--st-planned`, `--st-none`). У выбранной (красной) кнопки статуса точка белая, чтобы не терялась на красном фоне. Сам текст статуса цвет не меняет.

**Пометка прогресса на постере.** В левом нижнем углу постера, отступ 6px: фон `--text`, текст `--bg`, 11px, 700, `--r-xs`, `padding: 3px 6px`, формат `S2 · E4`. Показывается у сериалов в полке «Смотрю сейчас» и в сетке «Всё кино», когда известен прогресс.

**Полоска прогресса сериала.** Под постером сериала со статусом «Смотрю» (полка «Смотрю сейчас», сетка «Всё кино») — полоса 3px, `--r-pill`, фон `--surface-3`, заполнение `--st-watching`. Доля — ((сезон − 1) × серий / сезонов + серия) / серий, округляется в границы 0–100%; без известного числа серий или сезонов полоска не показывается.

**Карточка карусели.** Фон `--surface`, рамка 1px `var(--line)`, `--r-md`, `padding: 10px`. Внутри кадр 16:9 с `--r-sm`; в его левом верхнем углу, отступ 10px, — пометка статуса: точка 7px цвета статуса плюс подпись («Смотрю · S1 E3», «Буду смотреть», «Смотрел», «Не смотрел»), фон `rgba(18,18,23,.8)`, `--r-pill`, `padding: 4px 10px`, 11.5px, текст `--text`. Ниже дата добавления служебной подписью, название, метаданные, строка оценки по правилу «Подпись у оценки» выше — статус в этой строке больше не повторяется, он уже на кадре. Карточки в ряду — одной высоты (`align-items: stretch` у ряда, карточка на всю высоту колонкой); строка оценки держит место всегда, даже без оценки, иначе карточка без неё схлопывается ниже соседних.

**Полка на Главной.** Бокс: фон `--panel-sky`, рамка 1px `var(--panel-sky-line)`, `--r-lg`, `padding: 16px 20px 20px`, между боксами 20px. Внутри бокса — заголовок полки, затем горизонтальная прокрутка: ширина постера 104px, зазор `--gap`, правый край намеренно обрезан на половине карточки — подсказка, что прокрутка есть; у ряда обязателен вертикальный `padding`, иначе увеличенный при наведении постер подрежется краем прокрутки.

**Тот же бокс на других страницах.** Фон `--panel-sky` и рамка `--panel-sky-line` используются не только на полках Главной, но и: группы «Списки» и «Сохранённые фильтры» на странице «Списки» (заголовок группы — иконка, название 17px 700, счётчик как у полки; иконка «Списки» — `List` в `--orange`, «Сохранённые фильтры» — `RefreshCw` в `--sky`); каждый раздел статистики на «Статистике»; карточка диска в списке и сводка на странице диска (`/diski/[id]`). Во всех случаях — `--r-lg`, рамка `--panel-sky-line`, между боксами 20px. На Статистике и Дисках `padding` ровный — `20px` со всех сторон (не `16px 20px 20px`, как у полки); панель жанров и карусель этим цветом не окрашиваются, остаются на `--surface`.

**Полоса заполнения диска.** Дорожка `--surface-3`, заполнение `--sky`; при заполнении ≥ 90% заполнение красится в `--orange`. Красный для этой полосы не используется — он занят действиями и выбором (6.4).

### 6.6. Состояния

- **Наведение на постер:** `transform: scale(1.03)`, 150мс, `ease-out`. В полках у контейнера должен быть вертикальный `padding`, иначе увеличенный постер обрежется краем прокрутки.
- **Наведение на кнопку и пилюлю:** смена фона, 120мс.
- **Фокус с клавиатуры:** `outline: 2px solid var(--red); outline-offset: 2px`. Убирать `outline` запрещено, `:focus-visible` обязателен на всех интерактивных элементах.
- `@media (prefers-reduced-motion: reduce)` — все переходы и трансформации отключаются.

### 6.7. Сетка и адаптив

| Ширина | Сетка «Всё кино» | Карусель на Главной |
|---|---|---|
| ≥ 1280px | 6 колонок | 3 карточки |
| 900–1279px | 5 колонок | 3 карточки |
| 600–899px | 3 колонки | 2 карточки |
| < 600px | 2 колонки | 1 карточка, свайп |

Полки прокручиваются горизонтально на всех ширинах. Минимальная поддерживаемая ширина — 360px, горизонтального скролла страницы нет нигде.

На телефоне (< 600px) — логотип, поиск и «Добавить» в первой строке, ряд из пяти разделов всегда виден второй строкой, выход внизу страницы. Ряд — панель `--surface` с рамкой `--line`, `--r-lg`, `padding: 6px`; пункт 56px, иконка над подписью, активный — фон `--red` 14% и иконка `--red`; колонки не уже своей подписи, чтобы «Статистика» 11px влезала на 360px. Выход — строка «Вход: владелец · Выйти» под линией `--line` в конце каждой страницы, кроме `/vhod`; на preview и в dev её нет, на ПК выход в шапке.

### 6.8. Иконки

Только `lucide-react`, `stroke-width: 1.5`, размер 15–20px. Залитые варианты допустимы ровно для двух: звезда рейтинга и сердце избранного. Цвет наследуется от текста, кроме перечисленного в 6.4. Эмодзи не используются.

### 6.9. Прямые запреты

- **Не копировать фирменные элементы стриминговых сервисов** — логотип, шрифт, точный оттенок их красного. Знак у проекта свой: `MOVIE_THEATRE` с подчёркиванием в акценте.
- Градиенты запрещены, с одним исключением: вертикальное затемнение поверх кадра 16:9, чтобы текст поверх него читался. Больше нигде.
- `box-shadow` и `backdrop-filter` не используются; глубина передаётся ступенями `--surface`.
- Жёлтый вне рейтинга, красный в абзацах текста.
- Готовые UI-киты (shadcn, MUI, Chakra) — дают узнаваемый шаблонный вид.
- Анимационные библиотеки; хватает `transition` и `transform`.
- Заглушки в виде цветных прямоугольников: пустой постер — это `--surface-2` с иконкой, а не случайный цвет.
- Пустые полки с текстом «здесь пока ничего нет» — такая полка просто не отображается.
