## Принятые решения

- Метаданные тянутся один раз при добавлении, дальше только ручные правки. Кнопка «Перезаполнить из API» — ручная
- Один фильм или сериал = один диск. Вес и диск вводятся вручную при редактировании, вес необязателен
- Остаток диска = объём минус сумма введённых весов. «Подсчёт неполный», если у части фильмов веса нет
- Вход: Google, доступ только с одного email. Закрыт весь сайт. Логина и пароля нет
- PWA: только установка на экран, без офлайн-режима
- Полоса заполнения диска нейтральная, красного при переполнении нет
