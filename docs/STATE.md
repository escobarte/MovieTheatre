## Принятые решения

- Метаданные тянутся один раз при добавлении, дальше только ручные правки. «Перезаполнить из API» — ручная кнопка, этап 7
- Один фильм или сериал = один диск. Вес вводится вручную, необязателен
- Остаток диска = объём минус сумма введённых весов; «подсчёт неполный», если у части записей веса нет. Полоса заполнения нейтральная
- Вход: Google, один email (`ALLOWED_EMAIL`), закрыт весь сайт. Логина и пароля нет
- PWA: только установка, без офлайна
- `backdropUrl` входит в облегчённую выдачу (решено, в коде пока нет)
- Git ведёт владелец вручную, Claude Code его не трогает

## Известные проблемы и непроверенное

- **Правки по итогам ручной проверки (2026-11-16) сделаны и ждут проверки на Vercel.** Этапы 7–8 этим не начаты. Сделано: выпадающие списки «Статус» файла и «Диск» в карточке; единый стиль всех полей ввода; шапка в две строки на телефоне; скрытые полосы прокрутки и стрелки у строки жанров на Главной; отступ 14px у полок; сворачиваемая строка жанров в «Всё кино»; кликабельная статистика; режиссёры считаются по человеку, а не по строке целиком; сборные жанры сериалов раскладываются при импорте. У диска нет колонки `position` — выбор диска в карточке идёт в существующем порядке (по метке), как и список дисков. Поле «пометка» у диска стало редактируемым (раньше было только текстом).
- **Пустые кадры карусели на Главной.** Вероятная причина — `backdropUrl` не попадает в облегчённую выдачу `GET /api/movies`. Чинить на этапе 7
- **Сайт открыт без входа**, пока не сделан этап 7. Не вносить личные данные, которые не хочется показывать
- Не проверено на Vercel: добавление фильма (внешние запросы TMDB и КП в пределах лимита времени функции) и поиск TMDB. Если поиск отвечает 401 — в `TMDB_API_KEY` подставить длинный токен (Read Access Token)
- Этапы 3–6 и диски не прошли ручную проверку по чек-листам
- На этапе 3 Claude Code засеял тестовые фильмы в боевую базу и выставил выдуманные личные поля у трёх записей. Свои записи он удалил; статусы и оценки у оставшихся владельцу стоит перепроверить
- Колонка `storage` у `movies` заменена диском; проверить в `lib/db/schema.ts`, осталась ли она в схеме
