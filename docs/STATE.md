## Принятые решения

- Метаданные тянутся один раз при добавлении, дальше только ручные правки. «Перезаполнить из API» — ручная кнопка в карточке с подтверждением
- «Перезаполнить» не затирает поля Кинопоиска при его сбое: если КП не дал записи (лимит, ошибка, таймаут, не нашёл), `kpId`, оценки КП и IMDb и название остаются прежними; не ответил TMDB — запись не меняется вовсе
- Один фильм или сериал = один диск. Вес вводится вручную, необязателен
- Остаток диска = объём минус сумма введённых весов; «подсчёт неполный», если у части записей веса нет. Полоса заполнения голубая, с 90% — оранжевая, без красного
- Вход: Google, один email (`ALLOWED_EMAIL`), закрыт весь сайт, включая `/api`. Логина и пароля нет. Пустой `ALLOWED_EMAIL` не пускает никого
- Проверка входа выключена только при `VERCEL_ENV=preview` (preview закрывает защита Vercel) и в `next dev`; на боевом и в любом другом случае — включена
- PWA: только установка, без офлайна. Иконка — вариант «MT и хлопушка» (Onest 700, хлопушка вместо «_»); PNG в `public/` и `app/`, исходники SVG в `assets/pwa/`
- `backdropUrl` входит в облегчённую выдачу — сделано
- Карточка в двух режимах: обычный (текст; статус, оценка, прогресс, списки, файл и диск активны всегда) и правка по карандашу (все текстовые и числовые поля). «Сохранить» возвращает в обычный режим и карточку не закрывает. Разбор правки одинаковый в карточке и на сервере (`lib/movie-patch.ts`). Рейтинги и описание в карточке по-прежнему только для чтения
- Карточка и поиск живут в адресе (`?m=<id>`, `?search=1|add`): «Назад», в том числе на Android и в установленном приложении, закрывает их, а не приложение
- Git ведёт владелец вручную, Claude Code его не трогает
- Правки ведутся в ветках `fix/review-N`, проверяются на preview-адресе Vercel, в `main` сливает владелец сам

## Известные проблемы и непроверенное

- **Правки по итогам ручной проверки (2026-11-16) сделаны и ждут проверки на Vercel.** Этапы 7–8 этим не начаты. Сделано: выпадающие списки «Статус» файла и «Диск» в карточке; единый стиль всех полей ввода; шапка в две строки на телефоне; скрытые полосы прокрутки и стрелки у строки жанров на Главной; отступ 14px у полок; сворачиваемая строка жанров в «Всё кино»; кликабельная статистика; режиссёры считаются по человеку, а не по строке целиком; сборные жанры сериалов раскладываются при импорте. У диска нет колонки `position` — выбор диска в карточке идёт в существующем порядке (по метке), как и список дисков. Поле «пометка» у диска стало редактируемым (раньше было только текстом).
- **Карусель на Главной (2026-11-16, второй проход правок) — устранено.** Колонка `backdrop_url` есть в схеме с первой миграции, и импорт (`lib/merge.ts`) всегда её заполнял из TMDB — разрыв был только в `GET /api/movies` (облегчённая выдача не отдавала поле) и в `Carousel` (не читал его вовсе). Исправлено в обоих местах, записи не дозаполнялись. Раз импорт никогда не был сломан, у уже добавленных записей `backdropUrl` в базе, скорее всего, уже есть — кадр должен появиться сразу после деплоя у всех, у кого TMDB в принципе прислал кадр. Пусто останется только там, где у TMDB нет backdrop_path
- Не проверено на Vercel: добавление фильма (внешние запросы TMDB и КП в пределах лимита времени функции) и поиск TMDB. Если поиск отвечает 401 — в `TMDB_API_KEY` подставить длинный токен (Read Access Token)
- Колонка `storage` у `movies` заменена диском; проверить в `lib/db/schema.ts`, осталась ли она в схеме
